== Description ==

The Construction Equipments is designed for construction companies, heavy equipment rental agencies, civil engineering firms, and building contractors seeking a structured and professional web presence. It features a multipurpose layout that supports service listings, project showcases, and company information within a clean and organized interface. The design follows a minimal and modern approach with elegant typography and a sophisticated visual hierarchy suitable for industrial and technical businesses. Built with bootstrap, the theme is responsive and mobile friendly, ensuring consistent performance across desktops, tablets, and smartphones. It is Retina ready and uses optimized codes and clean code practices to support faster page load time and stable performance. The framework emphasizes secure and clean code, making it suitable for long-term website management by a Developer or in-house technical team. The homepage typically includes a prominent Banner section, Call to Action Button (CTA), testimonial section, and Team profiles to present company credentials and workforce details. Animated and interactive elements are included where appropriate, offering a dynamic yet professional browsing experience. Shortcodes simplify content placement, allowing structured presentation of services, equipment catalogs, and project portfolios. Customization Options and personalization options enable users to adjust colors, layouts, fonts, and content blocks without extensive coding knowledge. The Construction Equipments is translation ready, supporting multilingual websites for firms operating in multiple regions. Social media integration allows companies to connect their platforms directly from the site. Overall, the theme provides a beautiful yet practical framework with an agency friendly structure, suitable for businesses requiring a modern, structured, and visually polished online presence.

== Installation ==
	
1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.
